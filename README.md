# time-in-kgs

Exploratory notes for the NIH ODSS challenge **"It's About Time: Temporal Reasoning in
Biomedical Knowledge Graphs"**
(<https://www.nih.gov/challenges/its-about-time-temporal-reasoning-biomedical-knowledge-graphs-challenge>).
Phase 1 submissions are open 2026-10-05 to 2027-01-15.

The aim of this repo is to lay out what the challenge actually asks for, what a successful
temporal knowledge graph would need to be able to answer, and how existing knowledge-graph
tooling built at or with [RENCI](https://renci.org/) might contribute, so that colleagues can
decide whether and how to enter.

- [AGENTS.md](AGENTS.md): the challenge in one screen, the judging rubric, and the rules for
  working in this public repo.
- [competency-questions/](competency-questions/README.md): easy, medium, and hard questions a
  winning temporal KG should answer, across the three domains NIH names.
- [ideas/](ideas/README.md): candidate approaches and how each maps onto the rubric.
- [resources/](resources/README.md): annotated links to graphs, standards, tooling, and papers.
- [tools/](tools/README.md): small scripts, starting with a strict parse and reasoner check for
  OWL files.

Downloaded material and scratch files live in `data/`, which is not committed.
